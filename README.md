# Quiz-app
A python quiz app with scoring system

A simple command-line quiz application built with Python.

Features : 
1.Multiple choice questions (A/B/C/D)
2.Personalized greeting with your name
3.Score tracking
4.Performance feedback based on score

How to Run :
1. Make sure Python is installed
2. Run: python quiz.py
3. Answer all questions
4. See your final score!

Sample Output :

========================================
       WELCOME TO THE QUIZ APP!       
========================================
Enter your name: Rahul
Score: 4 / 5
🥇 Excellent! Great job!


Tools Used : 
1.Python 3.14
2.Core concepts: Lists, Dictionaries, Loops, Functions
